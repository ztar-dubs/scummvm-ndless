ScummVM for TI-Nspire CX CAS

A port of ScummVM to the TI-Nspire CX CAS calculator using the Ndless SDK.

1. Installation

1.1 Requirements

  • TI-Nspire CX CAS calculator with Ndless installed
  • Game data files (you must own the original games)

1.2 File Structure

Copy the following directory structure to your calculator (e.g. under /documents/scummvm/):

scummvm/
  scummvm.tns          <-- The executable
  data/
    encoding.dat.tns
    fonts.dat.tns
    gui-icons.dat.tns
    kyra.dat.tns        <-- Required for Kyra/EOB/LOL games
    lure.dat.tns        <-- Required for Lure of the Temptress
    scummclassic.zip.tns
    scummmodern.zip.tns
    scummremastered.zip.tns
    vkeybd_default.zip.tns
    vkeybd_small.zip.tns
  roms/
    mygame/             <-- One folder per game
      DATAFILE1.tns
      DATAFILE2.tns
      ...
  saves/                <-- Created automatically
Important: All files on the Nspire filesystem must have the .tns extension. Rename your game data files by appending .tns (e.g. RESOURCE.MAP becomes RESOURCE.MAP.tns).

1.3 Data Files Reference

FileSizeRequiredDescription
encoding.dat.tns176 KBRequiredCharacter encoding tables. Needed for correct text display in all games.
fonts.dat.tns6.1 MBOptionalAdditional font pack. Provides extra fonts for the ScummVM GUI. Can be removed to save space — the built-in font will be used instead.
gui-icons.dat.tns3.1 MBOptionalGame icons displayed in the ScummVM launcher. Can be removed to save space — generic icons will be shown instead.
kyra.dat.tns2.0 MBConditionalStatic resource data for the Kyra engine. Required to run Legend of Kyrandia 1-3, Eye of the Beholder 1-2, and Lands of Lore.
lure.dat.tns751 KBConditionalStatic resource data for the Lure engine. Required to run Lure of the Temptress.
scummclassic.zip.tns16 KBOptionalClassic ScummVM GUI theme (dark). Alternative to the default theme.
scummmodern.zip.tns63 KBOptionalModern ScummVM GUI theme. Alternative to the default theme.
scummremastered.zip.tns88 KBRecommendedRemastered ScummVM GUI theme. This is the default theme — without it, the built-in fallback theme is used (less polished but functional).
vkeybd_default.zip.tns181 KBOptionalScummVM's built-in virtual keyboard (standard size). Not used by this port (the Nspire has its own VKB), but harmless to keep.
vkeybd_small.zip.tns84 KBOptionalScummVM's built-in virtual keyboard (small size). Not used by this port.
Minimum install: To save space, you only need encoding.dat.tns plus the engine-specific data files for the games you want to play (kyra.dat.tns and/or lure.dat.tns). All other files are optional. Total minimum: ~176 KB (without Kyra/Lure games).

1.4 Adding a Game

  1. Create a folder for your game under roms/ (e.g. roms/monkey1/)
  2. Copy the game data files into that folder, adding .tns to each filename
  3. Launch scummvm.tns on the calculator
  4. Use "Add Game..." and browse to your game folder

2.2 Game Data Files

Each game engine requires specific files from the original game. Remove any executables (.EXE, .COM, .BAT) and configuration files (.CFG, .INI) - only keep the data files. Refer to the ScummVM wiki for detailed file lists per game.

Examples:

3.2 Remapping Keys

You can remap any action via the ScummVM Options menu:

  1. Press Menu (F5) to open the game menu
  2. Go to Options → Keymaps
  3. Click on the action you want to remap
  4. A virtual keyboard (VKB) will appear - select the desired key
  5. Press Enter or 5 to confirm, Esc to cancel

3.3 Virtual Keyboard (VKB)

KeyVKB Action
Arrows / 2, 4, 6, 8Navigate keys
Enter / 5Confirm selection
EscCancel remapping
TouchpadTouch to select key

Key colors: Yellow = cursor, Blue = current binding, Dark red = used by another action (blocked), Red = CLEAR (remove binding).

4.3 Hardware

  • Screen: 320x240, 16-bit RGB565
  • CPU: ARM926EJ-S (ARMv5TEJ)
  • No audio output (sound is disabled)
  • Touchpad for mouse control (with dynamic calibration)

4.4 Limitations

  • No sound (the TI-Nspire has no audio hardware)
  • SCUMM v7/v8 games are not supported (too demanding)
  • High-resolution games (640x480) may not display correctly
  • Limited storage space on the calculator
