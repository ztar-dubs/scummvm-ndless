ScummVM pour TI-Nspire CX CAS

Un portage de ScummVM sur la calculatrice TI-Nspire CX CAS via le SDK Ndless.

1. Installation

1.1 Prérequis

  • Calculatrice TI-Nspire CX CAS avec Ndless installé
  • Les fichiers de données des jeux (vous devez posséder les jeux originaux)

1.2 Arborescence des fichiers

Copiez l'arborescence suivante sur votre calculatrice (par ex. sous /documents/scummvm/) :

scummvm/
  scummvm.tns          <-- L'exécutable
  data/
    encoding.dat.tns
    fonts.dat.tns
    gui-icons.dat.tns
    kyra.dat.tns        <-- Requis pour les jeux Kyra/EOB/LOL
    lure.dat.tns        <-- Requis pour Lure of the Temptress
    scummclassic.zip.tns
    scummmodern.zip.tns
    scummremastered.zip.tns
    vkeybd_default.zip.tns
    vkeybd_small.zip.tns
  roms/
    monjeu/             <-- Un dossier par jeu
      FICHIER1.tns
      FICHIER2.tns
      ...
  saves/                <-- Créé automatiquement
Important : Tous les fichiers sur la Nspire doivent avoir l'extension .tns. Renommez vos fichiers de jeu en ajoutant .tns à la fin (ex : RESOURCE.MAP devient RESOURCE.MAP.tns).

1.3 Détail des fichiers du répertoire data/

FichierTailleRequisDescription
encoding.dat.tns176 KoRequisTables d'encodage de caractères. Nécessaire pour l'affichage correct du texte dans tous les jeux.
fonts.dat.tns6,1 MoOptionnelPack de polices supplémentaires pour l'interface ScummVM. Peut être supprimé pour gagner de l'espace — la police intégrée sera utilisée à la place.
gui-icons.dat.tns3,1 MoOptionnelIcônes des jeux affichées dans le lanceur ScummVM. Peut être supprimé — des icônes génériques seront affichées à la place.
kyra.dat.tns2,0 MoConditionnelDonnées statiques du moteur Kyra. Requis pour lancer Legend of Kyrandia 1-3, Eye of the Beholder 1-2 et Lands of Lore.
lure.dat.tns751 KoConditionnelDonnées statiques du moteur Lure. Requis pour lancer Lure of the Temptress.
scummclassic.zip.tns16 KoOptionnelThème classique (sombre) de l'interface ScummVM. Alternative au thème par défaut.
scummmodern.zip.tns63 KoOptionnelThème moderne de l'interface ScummVM. Alternative au thème par défaut.
scummremastered.zip.tns88 KoRecommandéThème remaster de l'interface ScummVM. C'est le thème par défaut — sans ce fichier, un thème intégré de repli est utilisé (moins esthétique mais fonctionnel).
vkeybd_default.zip.tns181 KoOptionnelClavier virtuel intégré de ScummVM (taille standard). Non utilisé par ce portage (la Nspire a son propre VKB), mais sans conséquence s'il est présent.
vkeybd_small.zip.tns84 KoOptionnelClavier virtuel intégré de ScummVM (petite taille). Non utilisé par ce portage.
Installation minimale : Pour économiser de l'espace, vous n'avez besoin que de encoding.dat.tns plus les fichiers spécifiques aux moteurs des jeux que vous voulez lancer (kyra.dat.tns et/ou lure.dat.tns). Tous les autres fichiers sont optionnels. Total minimum : ~176 Ko (sans jeux Kyra/Lure).

1.4 Ajouter un jeu

  1. Créez un dossier pour votre jeu sous roms/ (ex : roms/monkey1/)
  2. Copiez les fichiers de données du jeu dans ce dossier, en ajoutant .tns à chaque nom de fichier
  3. Lancez scummvm.tns sur la calculatrice
  4. Utilisez « Add Game... » et naviguez jusqu'au dossier de votre jeu

2.2 Fichiers de données des jeux

Chaque moteur nécessite des fichiers spécifiques du jeu original. Supprimez les exécutables (.EXE, .COM, .BAT) et fichiers de configuration (.CFG, .INI) — ne gardez que les fichiers de données. Consultez le wiki ScummVM pour les listes détaillées par jeu.

Exemples :

JeuFichiers requis
Jeux AGI (King's Quest 1...)LOGDIR, PICDIR, VIEWDIR, SNDDIR, OBJECT, WORDS.TOK, VOL.*
Jeux SCI (Quest for Glory...)RESOURCE.MAP, RESOURCE.0*, VERSION, *.SCR, *.HEP, *.MSG
Jeux SCUMM (Monkey Island...)*.LFL ou MONKEY.000/MONKEY.001 (varie selon le jeu)
Beneath a Steel SkySKY.DNR, SKY.DSK
Flight of the Amazon QueenQUEEN.1
Lure of the TemptressDISK1.VGA (ou similaire)

3.2 Reconfigurer les touches

Vous pouvez réaffecter n'importe quelle action via le menu Options de ScummVM :

  1. Appuyez sur Menu (F5) pour ouvrir le menu du jeu
  2. Allez dans Options → Keymaps
  3. Cliquez sur l'action que vous souhaitez reconfigurer
  4. Un clavier virtuel (VKB) apparaît — sélectionnez la touche souhaitée
  5. Appuyez sur Enter ou 5 pour confirmer, Esc pour annuler

3.3 Clavier virtuel (VKB)

ToucheAction VKB
Fléches / 2, 4, 6, 8Naviguer entre les touches
Enter / 5Confirmer la sélection
EscAnnuler l'affectation
TouchpadToucher pour sélectionner une touche

Couleurs des touches : Jaune = curseur, Bleu = affectation actuelle, Rouge foncé = utilisée par une autre action (bloquée), Rouge = CLEAR (supprimer l'affectation).

4.3 Matériel

  • Écran : 320x240, RGB565 16 bits
  • Processeur : ARM926EJ-S (ARMv5TEJ)
  • Pas de sortie audio (le son est désactivé)
  • Touchpad pour le contrôle de la souris (avec calibration dynamique)

4.4 Limitations

  • Pas de son (la TI-Nspire n'a pas de matériel audio)
  • Les jeux SCUMM v7/v8 ne sont pas supportés (trop gourmands)
  • Les jeux en haute résolution (640x480) peuvent ne pas s'afficher correctement
  • Espace de stockage limité sur la calculatrice
